# Hermes Duty Board

**Hermes のすべての会話から、あなたの対応待ちを 1 枚のライブダッシュボードに集約します。**

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語

![Duty Board のスクリーンショット](docs/screenshot.ja.png)

</div>

[Hermes Agent](https://github.com/NousResearch/hermes-agent) を Discord・Telegram・Feishu で使っていると、会話はすぐに何十ものスレッドに散らばり、次のようなことを見落としがちになります。

- エージェントが 2 日前に質問して、まだ返事を待っている。
- 自分が送ったメッセージに、結局返信が来ていない。
- バックグラウンドジョブが終わった頃には元のスレッドが切り替わっていて、結果が届いていない。
- 定期ジョブが火曜日から静かに失敗し続けている。

Duty Board はこれらを 1 ページにまとめ、5 秒ごとに更新します。各会話にはボタンがあり、ワンクリックでその会話に戻れます。

## 表示される内容

| セクション | 内容 |
|---|---|
| **あなたの返信待ち** | 最後の返信があなたへの質問や判断待ちで終わっている会話。待ち時間が長い順に、何を聞かれたか・きっかけになった発言を表示します。 |
| **あなたが送信しましたが返信がありません** | 最後に発言したのがあなたで、実行中のターンもない会話。多くの場合、取りこぼされたメッセージです。「あなたの返信待ち」の一番上に表示されます。 |
| **実行中** | いま進行中のターン。経過時間とエージェントが何をしているか（モデル応答待ち、ターミナル実行中など）を表示し、10 分以上動きがなければ警告します。 |
| **バックグラウンドジョブ** | 実行中の `delegate_task`。完了したのに元のセッションが切り替わっていて結果を届けられなかったものも一覧にします。 |
| **定期ジョブ** | エラー、配信失敗、一時停止、実行予定時刻の超過があるジョブと、次に実行されるジョブのタイムライン。 |
| **最近完了** | 直近 24 時間の返信のうち、質問ではなく報告で終わっているもの。「後で報告します」と約束した返信には印が付きます。 |
| **長期目標** | 実行中・一時停止中の `/goal`。ターン数と判定の直近の理由を表示します。 |

**すぐに飛べる**：「あなたの返信待ち」と「実行中」のカードには **Discord で開く** ボタンがあります。`discord://` で Discord デスクトップアプリの該当スレッドを開き、メッセージ ID が分かる場合はあなたの発言の位置まで移動します。ヘッダーの切り替えで、ブラウザで開くようにもできます。

**片付けたら消す**：「確認済み」を押すとカードを閉じます。その会話に新しいメッセージが来ると再び表示されます。

## 動作要件

- Hermes Agent **0.21.1 以降**と Web ダッシュボード（`hermes dashboard`）。
- 既定では Discord、Telegram、Slack、WhatsApp、Signal、Matrix、Mattermost、Feishu、DingTalk、WeCom、Weixin、QQ、BlueBubbles、メール、SMS のセッションを対象にします（`messaging_sources` で変更可能）。ジャンプボタンは現在 Discord のみで、他のプラットフォームの会話はボタンなしで表示されます。

## インストール

```bash
hermes plugins install xiaoyaner0201/hermes-duty-board
hermes plugins enable duty-board
```

プラグインの API ルートはダッシュボード起動時にマウントされるため、インストール後にダッシュボードを再起動してください。

```bash
hermes dashboard --stop && hermes dashboard
```

ダッシュボードを開くと、*Sessions* の前に **Duty Board** タブが追加されています。

## チャット概要

`/duty` は Discord などの Hermes チャットで短い概要を返信します。モデルは呼びません。`hermes duty` は同じ概要をローカル端末に表示し、`hermes duty --json` はスクリプト用に元のボード JSON を出力します。

- **チャットには Hermes 0.21.7 以降が必要**です。呼び出し元とセッションを確実に識別できない旧版ゲートウェイでは拒否します。端末コマンドとローカル CLI/TUI の `/duty` は **0.21.1 以降**で使えます。
- **`plugins.isolation: host` ではチャット要約を使えません**。プラグインホストはコマンドの引数だけを転送し、送信者を転送しないため、`/duty` は拒否します。ホストは CLI コマンドも登録しないため `hermes duty` も使えません。ダッシュボードは使えます。チャットと CLI の要約には既定の `isolation: in_process` を使ってください。
- **チャットでは所有者のみ**。`<HERMES_HOME>/duty-board/settings.json` の `owner` にプラットフォームのユーザー ID を設定します（`DUTY_BOARD_OWNER` でも可。マルチプロファイルのゲートウェイでは、ルーティング先プロファイル自身の `.env` から読みます）。他のユーザーはボードを読む前に拒否します。ローカル CLI/TUI はそのホームを読めるローカルアカウントを信頼するため、プラットフォーム ID は不要です。
- **1 対 1 の DM は詳細を表示。グループ・チャンネル・スレッド・グループ DM は既定で件数のみ**で、タイトル・引用・リンクは表示しません。詳細を出すのは、プラットフォームが 1 対 1 を保証できる場合だけです：Discord、Telegram、Feishu、Google Chat、Mattermost、ID が `D` で始まる Slack の DM（Slack はグループ DM も DM と報告します）。Matrix（`m.direct` のルームは 3 人以上のこともあります）とその他のプラットフォームは件数のみです。そこで `/duty full` を使うと、`"chat_full_in_channels": true` を明示的に設定しない限り、DM の案内を表示します。有効化しても既定は件数のみです。有効化すると、他の非公開会話のタイトルや場所が返信先の参加者全員に見える可能性があります。
- `/duty counts`、`/duty full lang=zh`、`hermes duty --counts`、`hermes duty --full --lang ja` が使えます。言語は明示引数、設定の `chat_language`、`HERMES_LANGUAGE`、Hermes の `display.language`（`config.yaml` のブロック形式）、英語の順で選びます。チャットと CLI は全 17 言語に対応します。

架空の `dev/demo_home.py` ホームからのチャンネル返信（実行結果そのまま）：

```text
当番ボード · 5件が返信待ち · 5件が実行中 · 定期ジョブの問題1件
5件が返信待ち
5件が実行中
1件の未配信結果
定期ジョブの問題1件
```

## 設定

設定はすべて任意です。既定値を変えたい場合は `~/.hermes/duty-board/settings.json`（`<HERMES_HOME>/duty-board/settings.json`）を作成します。

```json
{
  "owner": "123456789012345678",
  "hide_other_people_content": true,
  "people": { "123456789012345678": "自分", "234567890123456789": "田中" },
  "window_days": 7,
  "stall_seconds": 600
}
```

| キー | 既定値 | 意味 |
|---|---|---|
| `owner` | 未設定 | 「自分の会話」とみなすプラットフォームのユーザー ID。未設定ならダッシュボードとローカル CLI ではすべての会話を自分のものとして扱い、何も隠しませんが、チャットコマンドは拒否します。環境変数 `DUTY_BOARD_OWNER` でも指定できます。 |
| `hide_other_people_content` | `true` | `owner` を設定している場合、他の人の会話は「返信待ち」と「最近完了」に出しません。実行中のターンとバックグラウンドジョブは「〇〇との会話」とだけ表示し、内容もリンクも出しません。 |
| `chat_language` | Hermes の言語、次に `en` | チャット/CLI 概要の既定言語。`lang=` / `--lang` で上書きできます。 |
| `chat_full_in_channels` | `false` | 真偽値 `true` のみ、DM 以外で明示的な `/duty full` を許可します。 |
| `people` | `{}` | ユーザー ID ごとの表示名。未設定ならプラットフォーム上のユーザー名を表示します。 |
| `window_days` | `7` | 何日前までの会話を対象にするか。 |
| `stall_seconds` | `600` | 実行中のターンが何秒動きがなければ警告するか。 |
| `unanswered_grace_seconds` | `180` | あなたの最後のメッセージに何秒返信がなければ「あなたが送信しましたが返信がありません」に入れるか。 |
| `recent_done_hours` | `24` | 「最近完了」の対象時間。 |
| `goal_lookback_days` | `14` | これより古いゴールは件数だけを表示します。 |
| `messaging_sources` | 上記参照 | 対象にする Hermes のセッションソース。例：`["discord", "telegram"]`。 |

**共有スレッドについて**：Hermes は既定でスレッドごとに 1 つのセッションを共有するため、複数の人が同じスレッドで話すことがあります。最新のメッセージの送信者を Hermes が記録していればその人の会話として扱い、記録がなければスレッドを始めた人の会話として扱います。どちらの場合も、共有スレッドから表示される内容はそのスレッドの参加者全員がもともと見られるものです。DM とユーザーごとのグループセッションが混ざることはありません。

## 「あなたの返信待ち」の判定方法

プラグインはモデルを一切呼びません。最後の返信のうち、意味のある最後の 1〜2 行だけを見ます（添付・リンク・脚注は除外）。そこに疑問符（`?`、`？`、`؟`）か、判断をあなたに委ねる表現（「よろしいですか」「教えてください」、英語・中国語の同様の表現）があるかを調べます。長い報告の途中にある質問は数えません。

経験則に基づく判定なので、ときどき誤判定があります。その場合は「確認済み」で閉じてください。疑問符による判定はすべての言語で有効です。疑問符のない「判断を委ねる表現」は現在、英語・中国語・日本語のみに対応しています。他の言語のパターンも歓迎します。

## プライバシーと安全性

- **読み取り専用**：`state.db` を SQLite の `mode=ro` で開き、ほかに `cron/jobs.json` と `gateway_state.json` を読むだけです。
- **書き込みはダッシュボードでの非表示操作のみ**：チャット/CLI は書き込みも非表示操作もしません。ダッシュボードは自分用の非表示リスト `<HERMES_HOME>/duty-board/dismissed.json` だけを書きます。
- **ネットワーク通信なし・モデル呼び出しなし・認証情報に触れない**：`.env`、`auth.json` などトークンの保存場所は読みません。
- **チャットのプライバシー**：チャットでは設定した所有者のみが概要を要求できます。DM はタイトル・場所・時間を表示し（Discord では Web リンクも付きます）、共有の返信先では既定で件数のみです。チャンネルでの詳細表示を有効にすると、他の参加者にも非公開会話のメタデータが見えます。他人の非公開の会話内容は引き続き隠し、メンションと Markdown を無効化します。
- **ダッシュボードの認証の内側で動く**：API は他のダッシュボードプラグインと同じく `/api/plugins/duty-board/` にマウントされ、ダッシュボードへのログインが必要です。
- **Hermes の内部テーブルに依存**：読んでいるのは Hermes の内部テーブルで、外部向けに安定性が保証されたインターフェースではありません。将来のバージョンで構造が変わった場合、影響を受けたセクションは空になり警告が表示されますが、ページ全体は壊れません。その際は issue を立ててください。

## 多言語対応

Hermes ダッシュボードが提供する 17 言語すべてに対応しています：English、简体中文、繁體中文、日本語、한국어、Deutsch、Español、Français、Italiano、Português、Русский、Українська、Türkçe、Magyar、Afrikaans、Gaeilge、العربية（右から左）。ダッシュボードで言語を切り替えると、このタブもすぐに切り替わります。件数は各言語の複数形ルールに従い、時間・数値・リストはブラウザの `Intl` API で整形します。

翻訳は `dashboard/i18n/<locale>.json` にあり、`en.json` が基準です。ネイティブスピーカーによる修正を歓迎します。手順は [CONTRIBUTING.md](CONTRIBUTING.md#translations) を参照してください。

## 開発

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest
node --check dashboard/dist/index.js && node tools/build_i18n.mjs --check && node tests/js/i18n_check.mjs
```

`dev/harness/` を使うと、Hermes なしで合成データの Hermes ホームを使ってこのタブを表示できます。上のスクリーンショットもこの方法で撮っています。詳しくは [dev/README.md](dev/README.md) を参照してください。
